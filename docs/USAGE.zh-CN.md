# 简笔白板 · macOS

当前版本：1.9.0。新增聚光框、箭头和连续编号。工具栏缩为 76 点宽的双列图标，样式面板缩为 264 点宽。聚光框和普通吸色无需录屏权限；只有区域颜色配对需要屏幕读取授权。

保留 1.2.1 的闪退修复：工具栏使用系统原生文字控件，选择模式下也可撤销清空。安装更新前请退出旧版本，再替换原应用，避免误开旧副本。

双击「简笔白板.app」即可运行，也可以把它拖到「应用程序」文件夹。此版本适用于 Apple Silicon（M 系列芯片）的 Mac，macOS 13 或更高版本。

## 随手呼出，用完收起

- 启动后只显示屏幕左侧的铅笔入口和菜单栏图标，不弹白板、不进入绘图状态。
- 点击边缘入口展开工具条，默认透明选择模式，网页照常操作。点击画笔等工具才进入批注。
- 底部「收起」会隐藏工具条和批注，保留内容、颜色、模式和撤销记录；再次点入口恢复。
- 菜单栏可展开工具条、收起、关闭边缘入口或退出。关闭边缘入口后可只用菜单栏呼出。
- 收起不是退出；真正退出仍用菜单栏或绘图状态下 X / ⌘Q。不会自动开机启动；常驻绘图不要求额外权限。

## 两种模式

- **有画板**：直接画图或贴文字。在「样式和工具」顶部的下拉菜单选择「白板 / 黑板」，底色自动记住；工具栏相应显示「白」或「黑」。设置只改变背景，已有笔迹与红色文字不变。
- **透明**（无白板）：透明背景，在当前桌面与其他窗口上方画批注。进入时默认「选择」状态，点击、滚动可以直接穿透到下面的网页，已有批注仍然可见。
- 切换模式会保留当前内容；拖动工具条顶部移动位置。
- **选择（V）**：箭头模式，不绘图；透明时点击穿透到网页。工具栏始终可以点击，「清空」会清空并保持选择模式，不退出应用。
- 点击画笔、直线、方形或文字，进入绘图状态；画好后点击「选择 V」，可继续点击网页。工具面板保持悬浮，可拖到不挡网页的位置。
- 透明模式切到其他应用时自动回到选择状态，批注保留、点击穿透；白板模式切走会隐藏白色画布。继续批注请点工具条中的画笔；应用不在 ⌘Tab 列表里。

## 快捷键

工具条宽 76 个逻辑点，悬停图标查看名称与快捷键。双列依次为：选择 / 画笔、直线 / 箭头、方形 / 编号、文字 / 聚光框。红色高亮表示当前工具，底部保留工具名或下一个编号。「清空」删除当前笔迹并关闭聚光，「收起」仅隐藏，两者独立。

「样式和工具」顶部可设置白板 / 黑板底色，透明模式不受影响；面板原有尺寸不变。默认显示颜色、粗细滑杆和字号。精确数值在「精确颜色」内，直尺与吸色在「更多工具」内。长说明通过「？」或 ⌘/ 查看。清空等动作不保留选中状态。

## 箭头、编号与聚光框

- **E 箭头**：拖动绘制，Shift 约束角度；颜色、粗细沿用画笔。
- **N 编号**：单击依次放置 1、2、3…，大小随字号、颜色随画笔。撤销后自动补号，清空后从 1 开始；撤销清空恢复编号进度。
- **S 聚光框**：拖动框选，周围压暗，框内保持原画面。在透明模式按 V 后可操作下方页面，框内内容随网页正常变化。Esc 或 C 关闭；收起隐藏、展开恢复，屏幕布局变化时关闭。聚光不计入笔迹撤销历史。
- 聚光只绘制透明遮罩，不读取画面，不需要增加系统权限。拖动未完成时切换工具或应用，会保留上一个已完成的框。

## 颜色、直尺和吸色

- 点击大色块打开调色盘，小圆点为常用色；精确颜色支持 RGB / HEX 输入与回车应用。只影响新笔迹，文字仍为红色。
- 点击「直尺」后在画布拖动，显示距离、横纵差值与逻辑点距离。像素按当前屏幕渲染倍率换算，例如 2× 屏幕上 100 pt 为 200 px；不是网页 CSS px，也不保证等于显示器原生物理像素。仅支持当前画布，不支持跨屏测量。测量线不算笔迹，Esc、C 或切换工具可移除。
- 吸色时暂时隐藏白板和工具栏，使用系统放大镜定位像素。单击确认后显示 RGB，悬停读数查看 HEX，结果「⋯」内可复制 RGB 或用于画笔。Esc 取消，保留旧结果。
- 普通吸色无需屏幕录制权限。系统原生接口只在确认后返回颜色，不提供移动时的实时 RGB。

## 框选颜色配对

吸色后，点击 RGB 结果下方的「框选配对」，拖动选中图例或图片区域即可。匹配的颜色保持原亮度，非匹配部分压暗，区域外不变；不是识别图例或计算风速。

- 首次使用需允许屏幕读取权限。框选完成后只读该选区一次，不持续录制、不保存、不上传；拒绝不影响普通吸色。
- 不再有「首次请求 / 检查授权」。实际读取由系统检查权限，应用不另外申请、不自动重试，拒绝时才提供设置入口。不需要配置开发者证书或钥匙串。系统可能要求重新打开应用，更新后也可能需要重新确认授权。
- 结果为原位置的静态快照，不跟随网页滚动。容差默认每个 sRGB 通道 ±12，可调 0–40；0 为精确匹配。调节只重算这一张图，不再读屏。无匹配时会明确提示。
- Esc、右键、关闭按钮或收起可结束高亮；结束后释放图像引用，笔迹仍保留。框选或显示高亮时切换应用也会结束；已发出的读取会等待系统回调，结果仅在白板回到前台后显示，不抢焦点。
- 配对需要 macOS 15.2 或更高版本。选区限制在单个屏幕，最多 1600 万渲染像素。屏幕布局变化会取消；受保护内容可能读取失败。色彩管理、缩放和压缩可能影响颜色一致性，可适量调节容差。

画笔和文字默认为红色，文字使用系统等宽无衬线字体。面板可以调整笔画粗细和字号。Z 保留原文换行，贴上后可用 ⌘Z 撤销；很长的文字建议分段粘贴。

快捷键在本应用处于前台时生效。只展开工具条不会接管键盘；点击画笔等绘图工具后再用 A/Q/W/Z。文字输入框为透明背景，保留红色边框和文字，可以看见下方内容。输入框内 A、Q、W、X、Z、C 都是正常字母，⌘X 是剪切，⌘C 是复制，不会触发绘图工具切换、清空或退出。Enter 换行，⌘Enter 完成，Esc 取消输入。

## 数据与安装

内容仅保存在当前运行会话，退出后不保存。应用无需联网或辅助功能权限。普通吸色通过系统吸色器，仅返回选定颜色；主动框选配对时才申请屏幕读取权限，并仅读取一次选区。无持续录制、音频采集、截图保存或上传。只有执行粘贴时才读取剪贴板文字。

这是为当前 Mac 本地编译并临时签名的应用，没有 Apple 开发者公证。若通过网络转移到其他 Mac 后遇到系统验证提示，可在确认来源后按 macOS 提示使用「打开」或「隐私与安全性」中的「仍要打开」。

源码位于随附的「简笔白板-源码.zip」。安装 Xcode 或 Command Line Tools 后，在源码目录运行 `bash native/build.sh` 可重新编译。
