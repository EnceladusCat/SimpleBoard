# 简笔白板 · macOS

当前版本：1.4.0。新增玻璃白板与珊瑚红铅笔图标，并附带可重复生成图标的源码。保留 C 清空快捷键，不退出应用，可用 ⌘Z 撤销。工具栏和样式面板采用深色半透明磨砂玻璃，保留清晰文字、珊瑚红选中提示、紧凑尺寸与全部快捷键。白板画布仍为白色，透明画布功能不变。系统开启「减少透明度」时会自动降低透明效果，优先保证可读性。

保留 1.2.1 的闪退修复：工具栏使用系统原生文字控件，选择模式下也可撤销清空。安装更新前请退出旧版本，再替换原应用，避免误开旧副本。

双击「简笔白板.app」即可运行，也可以把它拖到「应用程序」文件夹。此版本适用于 Apple Silicon（M 系列芯片）的 Mac，macOS 13 或更高版本。

## 两种模式

- **有白板**：白色背景，直接画图或贴文字。
- **透明**（无白板）：透明背景，在当前桌面与其他窗口上方画批注。进入时默认「选择」状态，点击、滚动可以直接穿透到下面的网页，已有批注仍然可见。
- 切换模式会保留当前内容；工具面板可通过标题栏拖动。
- **选择（V）**：箭头模式，不绘图；透明时点击穿透到网页。工具栏始终可以点击，「清空」会清空并保持选择模式，不退出应用。
- 点击画笔、直线、方形或文字，进入绘图状态；画好后点击「选择 V」，可继续点击网页。工具面板保持悬浮，可拖到不挡网页的位置。
- 绘图状态下按 ⌘Tab 切到其他应用，批注层会隐藏；返回本应用时批注重新显示。「操作网页」状态下切换应用则保留批注和工具面板。

## 快捷键

1.2 版使用 144 像素宽的紧凑工具条，常用工具旁保留快捷键。红色高亮表示当前工具，底部显示绘图状态或「可操作下方应用」。「清空」与「退出 X」为独立按钮，避免混淆。

点击带滑杆图标的「样式」按钮可调整线宽和字号，并查看完整操作提示。旁边的「4/26」分别代表当前线宽和文字大小；调整后会同步更新。更多按钮说明可将鼠标悬停在按钮上查看。清空、贴文字、退出等操作按钮点击即执行，不保留选中状态；只有绘图工具显示当前选中高亮。

| 按键 | 操作 |
| --- | --- |
| V | 选择 / 操作；透明状态下可以点击网页 |
| A | 画笔 |
| Q | 直线 |
| W | 方形；按住 Shift 拖动画正方形 |
| T | 点击画布输入文字 |
| Z | 把剪贴板里的纯文字贴到鼠标所在位置 |
| C | 清空全部批注，不退出；⌘Z 可撤销 |
| X | 清空全部批注并退出应用 |
| ⌘Z / ⌘⇧Z | 撤销 / 重做 |
| ⌘V | 粘贴剪贴板文字 |
| ⌘Q | 退出应用 |

画笔和文字默认为红色，文字使用系统等宽无衬线字体。面板可以调整笔画粗细和字号。Z 保留原文换行，贴上后可用 ⌘Z 撤销；很长的文字建议分段粘贴。

快捷键在本应用处于前台时生效。文字输入框为透明背景，保留红色边框和文字，可以看见下方内容。输入框内 A、Q、W、X、Z、C 都是正常字母，⌘X 是剪切，⌘C 是复制，不会触发绘图工具切换、清空或退出。Enter 换行，⌘Enter 完成，Esc 取消输入。

## 数据与安装

内容仅保存在当前运行会话，退出后不保存。应用无需联网，不会读取屏幕或录制桌面，也不要求屏幕录制、辅助功能权限。只有执行粘贴时才读取剪贴板文字。

这是为当前 Mac 本地编译并临时签名的应用，没有 Apple 开发者公证。若通过网络转移到其他 Mac 后遇到系统验证提示，可在确认来源后按 macOS 提示使用「打开」或「隐私与安全性」中的「仍要打开」。

源码位于随附的「简笔白板-源码.zip」。安装 Xcode 或 Command Line Tools 后，在源码目录运行 `bash native/build.sh` 可重新编译。
